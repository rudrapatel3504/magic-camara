# 📷 Pixel Camera - Live Card Transposition

A camera app styled after Google Pixel Camera with live chromatic transposition.

---

## ✨ Features

- **Pixel Camera Interface**: Disguised completely as the Google Camera app, complete with zoom selector, shutter button, and settings sheet.
- **Pure Live Chromatic Transposition**: When a Red Playing Card is slid into the frame, it seamlessly appears in authentic Bicycle Navy Blue. Hands, fingers, and table are strictly preserved.
- **Zero Flash & Clean Disappearance**: When triggered via the shutter button or timer, the blue color cleanly fades away or directly disappears with no flashes or animations.
- **Shutter Button Trigger**: Tapping the shutter button reveals the red card (or re-arms back to blue).
- **Auto Timer**: Optional countdown timer (configurable in settings) to automatically fade the blue color.
- **Zero Audio / Zero Microphone**: Only standard camera access is requested.
